\section{Отчёт медика}

\begin{itemize}
	\item \textbf{Хронология похода}
	
	\begin{enumerate}
		\item \textbf{До похода} -- Руководитель за пару недель до похода получил травму ноги. К сожжению он не успел полностью восстановиться к старту.
		
		\item \textbf{4 января} -- Все участники похода здоровы. Без проблем прошли до лагеря <<Белый ключ>>. Подъём к перевалу <<Перья>> и спуск обратно группа успешно прошла. Вечером для профилактики повреждённой ноги руководитель воспользовался диклофенаком.
		
		\item \textbf{5 января} -- Вовремя отдыха на стоянке <<Гремучий ключ>> часть участников воспользовалась личным пластырем для обработки мозолей.
		Переход к вершине <<Круглица>> был без проблем. Группа успешно  протропила путь к стоянке <<Таганай>>. 
		
		\item \textbf{6 января} -- Этот день прошёл без осложнений.
		
		\item \textbf{7 января} -- Часть участников жаловалась на плохой сон из-за дождя из конденсата вызванного ветром. Группа без событий смогла подняться к курумникам Ицыла. Из-за длительного поиска тропы к седловине несколько участников жаловалось на лёгкую гипотермию. Непосредственно у седловины один из участников легонько ушиб колено из-за проваливания в щель между камнями. Группа завершила день без дополнительных осложнений. Вечером для профилактики повреждённой ноги руководитель опять воспользовался диклофенаком. Часть участников воспользовалась пластырем для обработки мозолей.
		
		\item \textbf{8 января} -- Сам день прошёл без осложнений, но из-за длительности перехода к позднему вечеру у команды накопилась усталость.
		
		\item \textbf{9 января} -- Группа без проблем добралась до озера Тургояк и сумела дойти по льду до острова Вера. Перед осмотром достопримечательностей острова хронометрист пожаловался на осложнения в животе. Так как это скорее всего было вызвано питьё им сырой воды из реки возле прошлой ночёвки я дал ему \textbf{фильтрум}. Завершила маршрут группа без проблем.
		
		\item \textbf{После похода} -- Ни у кого не было замечено осложнений. Осложнения в ЖКТ у хронометриста прошли ещё 9 января. Поход не усугубил повреждения ноги у руковода.
	\end{enumerate}
	
	\item \textbf{Выводы}
	
	\begin{itemize}
		\item В целом, поход был без серьёзных заболеваний и повреждений.
		\item Проблем с составом аптечки не было. 
	\end{itemize}
	
\end{itemize}

\paragraph{Аптечка на группу и рекомендации по личной аптечки}
